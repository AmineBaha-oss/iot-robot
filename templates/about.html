System Architecture

This IoT Smart Robot Car system consists of:

  • Raspberry Pi: Main controller running Python applications
  • Sensors: Ultrasonic distance sensor, IR line sensors (left, center, right)
  • Actuators: DC motors, LEDs, buzzer, servos
  • Adafruit IO: Cloud platform for real-time data streaming via MQTT
  • Cloud Database: Neon.com PostgreSQL for historical data storage
  • Local Database: SQLite for offline data storage and sync
  • Flask Web App: Web interface for monitoring and control

Features

  • Real-time sensor data monitoring
  • Historical data visualization with Chart.js
  • Remote car control (forward, backward, left, right)
  • Line following algorithm
  • Obstacle avoidance algorithm
  • Offline data storage with automatic sync
  • Device control (motors, LEDs, buzzer)
